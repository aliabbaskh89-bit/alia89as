# مهامي 🎨✅

تطبيق محلي على التلفون للمصمم: تنظّم **العملاء** و**الأوردرات** و**مهامك اليومية**، بنفس واجهة وترتيب تطبيق «مصروفي».

كل البيانات محفوظة **على تلفونك فقط**، بدون سيرفر ولا حساب.

## المميزات
- 🏠 **الرئيسية**: نسبة إنجاز مهام اليوم، وعدد الأوردرات الشغّالة، والتسليمات خلال الأسبوع، والفلوس الباقية عند العملاء. وفيها شريط أيام الأسبوع، ومهام اليوم المختار مع تسليماته، والمهام المتأخرة، وأقرب التسليمات
- ✅ **مهام**: لكل مهمة يوم ووقت وأهمية (عادي / مهم / عاجل 🔥)، وتقدر تربطها بأوردر، وتأشّرها بضغطة وحدة
- 📦 **أوردرات**: عميل، نوع شغل، سعر، عربون، موعد تسليم، تفاصيل. وحالات: جديد ← قيد التنفيذ ← بانتظار الملاحظات ← تم التسليم (أو ملغي)
  - تسجيل الدفعات («استلمت» أو «استلمت المبلغ كامل»)
  - مهام خاصة بكل أوردر
  - 📤 إرسال تفاصيل الطلب للعميل (السعر، المدفوع، الباقي، موعد التسليم)
  - فلترة: الحالية / المتأخرة / غير مدفوعة / المسلّمة، مع بحث
- 👥 **عملاء**: رقم وملاحظات، زر اتصال وواتساب، كل أوردرات العميل، المستلم منه والباقي عليه
- 📊 **تقارير** يومية / أسبوعية / شهرية: المهام المنجزة، الأوردرات المسلّمة، الوارد، نسبة الإنجاز، التسليم بالموعد، المقارنة مع الفترة السابقة، الوارد حسب نوع الشغل وحسب العميل
- 🔔 **تذكير صباحي** (افتراضياً 9:00) بمهام اليوم والتسليمات والمتأخرات، و**تذكير بوقت كل مهمة**
- 🏷️ أنواع شغل قابلة للتعديل، 💾 نسخ احتياطي واستيراد

## التثبيت على أندرويد
1. كل تغيير داخل مجلد `tasks-app` يخلّي GitHub Actions يبني ملف APK تلقائياً.
2. من تلفونك افتح صفحة **Releases** بالمستودع، ونزّل `mahami.apk` من إصدار **مهامي — آخر نسخة**.
3. ثبّته، وأول ما تفتحه اسمح بالإشعارات.

## التثبيت على الآيفون 🍏 (عبر Vercel)
التطبيق ينشر كمشروع Vercel مستقل، مجلده الجذر `tasks-app`:
- `web/` فيه الواجهة، و`api/` فيه دوال الإشعارات (`vapid`, `subscribe`, `unsubscribe`, `test`, `cron`).
- الاشتراكات تنحفظ بـ **Upstash Redis** (من Vercel ← Storage)، ومفاتيح VAPID تتولّد تلقائياً.
- الملف `.github/workflows/mahami-cron.yml` ينادي `/api/cron` كل 5 دقائق. الرابط ياخذه من `deploy-url.txt` أو من متغير المستودع `MAHAMI_URL`.
- مهامك وأوردراتك تبقى على التلفون. السيرفر يعرف بس وقت التذكير وأوقات المهام كأرقام، ونص الإشعار ينكتب على التلفون نفسه.

على الآيفون: افتح الرابط من Safari ← زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية» ← افتح مهامي من الأيقونة ← الإعدادات ⚙️ ← «فعّل التذكير». يحتاج iOS 16.4 أو أحدث.

## التجربة محلياً

cd tasks-app && npm run serve   # http://localhost:8081
