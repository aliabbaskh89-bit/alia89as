# ⚡ Ali Kit — أدوات المونتاج داخل Premiere Pro

إضافة (Panel) لبريمير بيها 17 أداة، والقوالب كلها مصممة بالكود فتتغير بالنص واللون اللي تختاره.

## التنصيب (ماك)
1. دبل كلك على `install-mac.command`. إذا ماك منع تشغيله: كلك يمين ← Open.
2. سكّر بريمير وافتحه من جديد.
3. من القائمة: **Window ← Extensions ← Ali Kit**
4. افتح ⚙ الإعدادات وحط مفاتيح الخدمات اللي تحتاجها.

> بريمير المدعوم: نسخة 2022 (22.0) وأحدث. تحتاج **ffmpeg**، والمنصّب يحاول ينصبه تلقائياً عبر Homebrew.

## الأدوات

| الأداة | شنو تسوي | تحتاج مفتاح؟ |
|---|---|---|
| مكتبة القوالب (23 قالب) | نصوص متحركة، زجاج، إشعارات، زر اشتراك ويا مؤشر، عداد، أسهم، فلاش، تسريب ضوئي... تنرندر فيديو شفاف وتنحط على التايملاين | لا |
| الكابشن التلقائي | تفريغ عربي بلهجتك (عراقي، خليجي، مصري...) + 7 ستايلات متحركة + تعديل النص + تصدير SRT | ElevenLabs أو OpenAI |
| Auto Cut | يحذف السكتات، وقبلها يحفظ نسخة احتياطية من السيكونس | لا |
| مونتاج البودكاست | يبدّل الكاميرا حسب منو دا يحچي (2-4 كاميرات + لقطة واسعة)، أو يرتب الكاميرتين فوق بعض للريلز | لا |
| Speed Ramp | محرر منحنى + 8 بريستات + عكسي + بومرانج + دمج فريمات | لا |
| مكتبة الانتقالات | زووم، سلايد، لف، اهتزاز، تلاشي (كـ keyframes تكدر تعدلها) + فلاش، تسريب ضوئي، مسح دائري | لا |
| تتبع الحركة | تحدد شي بالفيديو، فيتتبعه، ويثبّت عليه نص أو عنصر | لا |
| الرسم المتحرك | قلم، سهم، دائرة، هايلايتر، وكلها تنرسم بالفيديو | لا |
| إزالة الخلفية | للصور أو للفريم الحالي من الفيديو | remove.bg |
| التنزيل | ينزّل فيديو من رابط ويحطه بالمشروع | لا (يحتاج yt-dlp) |
| بحث الوسائط | صور وفيديوهات مجانية من Pexels | Pexels (مجاني) |
| مؤثرات صوتية AI | تكتب وصف المؤثر، فينولد وينحط عند المؤشر | ElevenLabs |
| تنظيف الصوت | إزالة ضوضاء، كمبريسر، وتوحيد مستوى الصوت (بودكاست / ريلز) | لا |

كل الملفات الناتجة تنحفظ بـ `~/Documents/Ali Kit Media/`، وتنضاف لبن اسمه **Ali Kit** جوة المشروع.

## التطوير
- `jsx/host.jsx`: أوامر بريمير (ExtendScript)
- `js/core.js`: الجسر ويا بريمير، و ffmpeg، و HTTP، والإعدادات
- `js/render.js`: يرسم على canvas ويطلع فيديو شفاف (ProRes 4444 / Animation)
- `js/templates.js`: القوالب. تكدر تضيف قالب جديد بنفس الشكل
- `js/analysis.js`: خوارزميات السكتات، والمتحدث، والسرعة، والتتبع
- `js/tools/*.js`: كل أداة بملف

الاختبارات:
```bash
node test/analysis.test.js   # الخوارزميات على صوت وفيديو حقيقي
node test/ui.test.js out/    # صور شاشة لكل أداة + فحص الرندر الشفاف
```
لفتح أدوات المطور وقت تشغيل الإضافة جوة بريمير: افتح المتصفح على `http://localhost:8088`.
