# WinCleaner - أداة تنظيف ويندوز

أداة لفحص الفيروسات وحذف الملفات المؤقتة لتفريغ مساحة القرص **C**.

## طريقة التشغيل
1. انسخ الملفين `WinCleaner.ps1` و `Run-WinCleaner.bat` إلى نفس المجلد على جهاز الويندوز.
2. انقر نقراً مزدوجاً على **`Run-WinCleaner.bat`** ووافق على طلب صلاحيات المسؤول.
3. اختر رقماً من القائمة (الخيار **5** يقوم بكل شيء).

> يُفضّل إغلاق المتصفحات والبرامج قبل التنظيف. ويُفضّل استخدام **Windows Terminal** لعرض العربي بشكل صحيح.

## القائمة
| الرقم | الوظيفة |
|---|---|
| 1 | حذف الملفات المؤقتة: Temp للمستخدمين وللويندوز، كاش Chrome / Edge / Firefox، تقارير الأعطال، ملفات تحديثات ويندوز المُنزّلة، كاش Delivery Optimization، سلة المحذوفات |
| 2 | تنظيف عميق: DISM لتنظيف WinSxS، أداة تنظيف القرص بكل خياراتها (تشمل Windows.old)، تعطيل السبات اختيارياً لحذف hiberfil.sys |
| 3 | فحص فيروسات سريع بـ Microsoft Defender (مع تحديث التعريفات وحذف التهديدات) |
| 4 | فحص فيروسات شامل لكل الملفات |
| 5 | الكل: فحص سريع + تنظيف كامل + عميق |
| 6 | عرض أكبر الملفات (فوق 300MB) في مجلدات المستخدمين — للعرض فقط |
| 7 | فحص قبل الإقلاع (Offline Scan) ضد الفيروسات المختبئة — يعيد تشغيل الجهاز |

## الأمان
- لا تحذف الأداة أي ملفات شخصية (المستندات، الصور، سطح المكتب، **التنزيلات**).
- كلمات المرور والكوكيز في المتصفحات لا تُحذف، فقط الكاش.
- يُحفظ سجل بكل العمليات على سطح المكتب باسم `WinCleaner-log-....txt`.
- إذا كان لديك برنامج حماية آخر غير Defender، فخيار فحص الفيروسات سيخبرك بذلك وعليك الفحص ببرنامجك.
