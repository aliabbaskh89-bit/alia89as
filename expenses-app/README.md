# مصروفي 💸

تطبيق محلي على التلفون لإدارة الفلوس: تسجّل كل **مصروف** و**وارد**، ويطلعلك **تقرير يومي وأسبوعي وشهري**، ويوصلك **إشعار كل يوم الساعة 11 مساءً** بملخص يومك.

كل البيانات محفوظة **على تلفونك فقط** — ماكو سيرفر ولا حساب ولا إنترنت.

## المميزات
- ➕ إضافة مصروف أو وارد بثواني (مبلغ + فئة + ملاحظة + تاريخ ووقت)، مع مبالغ سريعة جاهزة
- 🏠 الرصيد الكلي، وارد ومصروف الشهر، وشريط الميزانية الشهرية
- 📊 تقارير يومية / أسبوعية / شهرية: الوارد، المصروف، الصافي، مخطط الصرف حسب الأيام، الصرف حسب الفئة، مصادر الوارد، المقارنة مع الفترة السابقة، نسبة الادخار، أكبر مصروف
- 🔔 إشعار يومي (افتراضياً 11:00 مساءً، تقدر تغيّره) فيه وارد ومصروف وصافي اليوم، ويضيف ملخص الأسبوع بآخر يوم بالأسبوع وملخص الشهر بآخر يوم بالشهر
- 🧾 سجل كامل مع بحث وفلترة، وتعديل/حذف أي عملية
- 🏷️ فئات قابلة للتعديل (تضيف فئاتك الخاصة)
- 📤 مشاركة التقرير كنص (واتساب، تلغرام…)
- 💾 نسخ احتياطي واستيراد

## التثبيت على تلفون أندرويد
1. كل ما يتغيّر شي داخل مجلد `expenses-app` يبني GitHub Actions ملف APK تلقائياً.
2. افتح من تلفونك صفحة **Releases** بالمستودع ونزّل `masrufi.apk` من إصدار **مصروفي — آخر نسخة**.
3. افتح الملف واسمح بـ"التثبيت من مصادر غير معروفة" إذا طلب.
4. أول ما تفتح التطبيق اسمح بالإشعارات. من **الإعدادات ← التنبيه اليومي** تقدر تجرّب الإشعار.

> 💡 بعض التلفونات (شاومي، سامسونج، هواوي…) توقف إشعارات التطبيقات حتى توفّر البطارية. إذا ما وصلك الإشعار: إعدادات التلفون ← التطبيقات ← مصروفي ← البطارية ← **بدون قيود**.

## التثبيت على الآيفون 🍏 (عبر Vercel)
التطبيق ينشر كمشروع Vercel مستقل (مجلد `expenses-app`):
- `web/` الواجهة، و`api/` دوال الإشعارات (`vapid`, `subscribe`, `unsubscribe`, `test`, `cron`).
- الاشتراكات تنحفظ بـ **Upstash Redis** (من Vercel ← Storage)، ومفاتيح VAPID تتولّد تلقائياً وتنحفظ هناك.
- `.github/workflows/masrufi-cron.yml` ينادي `/api/cron` كل ربع ساعة (الرابط من `deploy-url.txt` أو متغير المستودع `MASRUFI_URL`)، وVercel Cron مرة يومياً كاحتياط.
- البيانات المالية تبقى على التلفون؛ الـ service worker يحسب التقرير وقت وصول التنبيه.

على الآيفون: افتح رابط Vercel من Safari ← زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية» ← افتح التطبيق من الأيقونة ← الإعدادات ← «فعّل التنبيه». يحتاج iOS 16.4+.

## التشغيل كنسخة ويب (للتجربة)
```bash
cd expenses-app
npm run serve   # ثم افتح http://localhost:8080
```
بالمتصفح الإشعار يوصل بس إذا التطبيق مفتوح؛ للإشعار الكامل استخدم نسخة الـ APK.

## البناء يدوياً (إذا عندك Android Studio)
```bash
cd expenses-app
npm install
./scripts/prepare-android.sh
npx cap open android   # أو: cd android && ./gradlew assembleDebug
```

## ملاحظات تقنية
- واجهة HTML/CSS/JS بدون أي مكتبات، ملفوفة بـ Capacitor 8.
- الإشعارات عبر `@capacitor/local-notifications`: التطبيق يجدول إشعار لكل يوم من الـ30 يوم الجاية، ويعيد الجدولة كل ما تضيف/تعدّل عملية أو تفتح التطبيق، حتى يكون رقم اليوم محدّث.
- `keystore/debug.keystore` مفتاح توقيع ثابت حتى تنزل التحديثات فوق النسخة القديمة بدون ما تنمسح بياناتك.
